# eglantine-covers

Game names and cover art for [Eglantine](https://github.com/Djihads80/Eglantine)'s Discord Rich Presence.
Eglantine looks up the running game's title ID here: `<TITLEID>.txt` holds the name and `<TITLEID>.png` the cover.

## Adding a game

Open a pull request with two files named after the game's 16-digit title ID:
- `<TITLEID>.txt`: the game's name, on one line
- `<TITLEID>.png`: a square cover (512x512 or larger)

Thanks to everyone who has contributed covers!
